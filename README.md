# The Worlds Within / Sphere Lab

A dependency-free literary particle study with short, attributed excerpts from Jorge Luis Borges's *El remordimiento* and Albert Camus's *Return to Tipasa*. Source links are included beside each excerpt. The surrounding reflections are original editorial text, not quotations.

Open `dist/index.html` directly or serve `dist` with a static server. No build is required.

This is an example for sofia
