# The Worlds Within / Sphere Lab

A dependency-free literary particle study with short, attributed excerpts from Jorge Luis Borges's *El remordimiento* and Albert Camus's *Return to Tipasa*. Source links are included beside each excerpt. The surrounding reflections are original editorial text, not quotations.

Open `dist/index.html` directly or serve `dist` with a static server. No build is required.

The warm-paper and dark-ink theme retains horizontal drag rotation, double-click entry into the readings, native vertical scrolling, and hidden scrollbars. Reduced-motion preferences disable automatic motion and smooth page scrolling. The controls panel, audio playback, microphone input, and saved settings have been removed.

Validation: JavaScript syntax and a mocked DOM/canvas smoke check passed at 390px, 430px, and 1440px, with reduced motion on and off. The smoke check exercises startup, rendering, pointer events, and scroll handlers; it does not establish visual layout or native touch behavior. Browser visual verification remains unavailable because the Windows browser automation was blocked by URL-policy support.

The opening sphere is centered. Its surface stretches, compresses, and twists through a continuous membrane field. Scroll to enlarge it and expand its particles into a full-screen 3D cloud before the readings enter; scroll back to reassemble it. Double-click advances into the transition. Native browser zoom is unchanged. Original inline SVG labyrinth and Mediterranean illustrations accompany the excerpts. Reduced motion skips the deformation and cloud animation. Rendering smoke checks at 390px, 430px, and 1440px passed; visual browser and physical touch verification remain unperformed.
